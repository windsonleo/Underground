# Checklist de acessibilidade

- Contraste da paleta verificado programaticamente para combinações usadas.
- Link para pular ao conteúdo e estrutura com cabeçalho, navegação e `main`.
- Todos os controles são alcançáveis por teclado e têm foco visível.
- Navegação informa destino atual com `aria-current`.
- Ícones decorativos são ocultos; botões têm nomes textuais.
- Mensagens de mudança de tela usam região `aria-live`.
- Movimento é reduzido quando solicitado pelo sistema.
- Layout suporta ampliação e telas estreitas sem navegação horizontal obrigatória.

Pendente: teste com utilizadores e leitores de tela reais, zoom de 400%, alto contraste do sistema e auditoria WCAG completa.
