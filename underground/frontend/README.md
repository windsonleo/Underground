# Frontend — protótipo navegável

Interface estática, responsiva e sem dependências externas. Serve somente para validar fluxo e hierarquia visual.

Execute `python3 -m http.server 4173` neste diretório. Use a navegação lateral/inferior e os botões principais para percorrer as telas. O seletor no rodapé alterna pt-BR e pt-PT; a preferência fica apenas no navegador.
